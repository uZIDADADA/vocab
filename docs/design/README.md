# Vocab logo exploration

The retained character explorations deliberately avoid owls, birds, books,
chat bubbles, microphones, robots, brains, and stars.

1. `vocab-character.png` — expressive character built from a `v`.
2. `vocab-cream-v2.png` — selected cream, near-black, and coral palette with the
   V character placed inside the Android adaptive-icon safe area.
3. `vocab-cream-foreground.png` — transparent foreground extraction used by
   the Android adaptive launcher icon.

The selected direction is exported to Android legacy and adaptive launcher
resources. A clean vector master is still desirable before a store release.
